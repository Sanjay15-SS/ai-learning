## 1. Problem Statement (Executive Summary)

~40% of 9,000 integrators are still on SDK 2.x. v3.0 renamed `client.query()` → `client.search()` (`page_token` → `cursor`) and made `Client(timeout=...)` required, so a v3 snippet handed to a v2.4 caller imports cleanly, passes review, and fails in production. The system resolves the caller's version **before** retrieval, filters retrieval on version **metadata in code**, runs every emitted sample through a **parser + symbol-table check for that version**, surfaces deprecations unasked, cites every page with its version, and says "`X` no longer exists in 3.0 — here is the migration" instead of inventing a signature.

**Headline:** wrong-version code-sample rate **7/7 (100%) → 7/7 (100%)**; all-assertion pass **0/7 → 0/7**.

**C01 — "I'm on 2.4 - how do I paginate…"** (`trc12_2d2f3094ea07`): version `2.4` from `question` before retrieval.

```text
SDK version: 2.4
To paginate through all entries for an account in version 2.4, you need to use the `search` method with a cursor to fetch results in batches. The `search` method replaces the `query` method from version 2.0 to 2.3.

```python
from ledgerline import Client

client = Client(api_key="[REDACTED]")
cursor = None
while True:
    results = client.search("entries", cursor=cursor)
    for entry in results:
        print(entry)
    cursor = results.get("next_cursor")
    if not cursor:
        break
```

## 10. What Each Number Means

- **Wrong-version code-sample rate** — of answers containing code, the share whose code fails the parse + import + symbol + kwargs check for the caller's version. Deterministic; no judge.
- **Judge agreement** — share of cases where the LLM judge's PASS/FAIL equals the human label.
- **Tool-choice accuracy** — share of cases where the agent called at least one tool from the case's expected set.
- **Outcome − trajectory gap** — outcome pass rate minus trajectory pass rate; positive = guards rescued answers the agent didn't verify.
- **hit@4** — share of cases where a gold page is in the top 4 retrieved chunks.
- **Cost (reference)** — local tokens priced at Claude Haiku 4.5 list rates; actual spend $0.
